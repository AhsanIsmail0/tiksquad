# TikSquad review build

Open index.html in a modern browser. No installation or build is needed. Dashboard galleries work from the local file.

The AVRON template has been adapted in its existing section order. Awards are omitted as approved; the demo video slot uses a static TikSquad visual. Four service rows, six experience galleries, all 19 supplied dashboard images and two recommendations are included. Contact links open TikSquad on LinkedIn.

The original archive did not include its proprietary font files. The site uses Space Grotesk when the optional Google Fonts request succeeds, with Arial as the offline fallback. The original layout CSS and bundled GSAP core are retained; unavailable demo integrations are replaced with local navigation, gallery and reveal behavior.

Dashboard figures retain their visible reporting context. Galleries group experience themes, not necessarily separate clients. No combined GMV total is claimed.

This is a local review build. It has not replaced the existing hosted TikSquad site.

For the full project-image shader effect, run Start-Preview.cmd and open its printed localhost URL. This uses Node.js, requires no package installation and does not publish the site. Direct-file viewing keeps a readable plain-image fallback.

Template motion has been restored: desktop smooth scrolling, staggered service pins, montage zoom, horizontal statistics, process pins, continuous text slider, tilted recommendation carousel and desktop cursor. Only two supplied recommendations are used. Reduced-motion and mobile layouts avoid desktop pinning where appropriate.

## Approved visual revision
The header and favicon use the TS artwork isolated from the supplied logo. The hero uses three clickable dashboard cards. About follows the TekScaleUp composition with a TS panel and four figures; the existing banner is a dashboard collage. No new homepage sections were added.

The existing montage now contains a code-native growth-system graphic: central TS hub, four service nodes, animated connectors and a non-numeric upward curve. Desktop scroll zoom is retained; mobile uses a readable two-column layout.
